# KBC-GAME

# 🎙 KBC Voice Quiz Game 🎮 | Python Project

Welcome to *KBC - Kaun Banega Crorepati Voice Quiz Game*, a Python-based voice-interactive quiz game that replicates the feel of the popular Indian TV show! With voice recognition 🎤, speech output 🗣, a timer ⏳, and Zira (AI voice assistant) – this game makes learning and playing super fun and interactive.

## 🧠 About the Project

This project is inspired by the famous quiz show *"Kaun Banega Crorepati" (KBC)* and developed entirely in Python. It uses voice recognition and text-to-speech to provide a real-time interactive game experience.

🔹 User listens to the questions and options using Zira voice  
🔹 Answers are given *via voice (A/B/C/D)*  
🔹 Instant feedback with speech + text  
🔹 Milestone system like the real KBC  
🔹 Game ends on wrong answer or no response

## 🎊 Features

- 🎤 Voice Input using speech_recognition
- 🗣 Text-to-Speech Output using pyttsx3 (Zira voice)
- 🖼 Styled terminal with pyfiglet banner
- 🎯 15 Questions with Multiple-Choice Options
- ⏰ 10 seconds timeout for each answer
- 🎉 Milestones (like ₹40,000, ₹6,40,000, etc.)
- 💬 Interactive speech messages in *Hindi*
- 🧠 Educational + Fun
